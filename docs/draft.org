#+name: Description
#+begin_quote org
The PARA method is a universal system for organizing digital and physical information. The acronyms stand for *Projects*, *Areas*, *Resources*, and *Archives*. It categorizes information based on how actionable it is, making it easy to store and retrieve data instantly
#+end_quote

#+name: PARA Overview
#+begin_html html
<img src="https://fortelabs.com/wp-content/uploads/2017/02/3-BASB_Illos_Gray_211015_PARA-1024x537.jpg" style="width:50%;"/>
#+end_html

- *Project* - short-term efforts (in your work or personal life) that you take on with a certain goal in mind
  + Complete a webpage design
  + Buy a new computer
  + Write research report

- *Area* - Important parts of you work and life that require ongoing attention. These might include:
  + Work responsibilities such as marketing, Human Resources Product Management ,Research and Development
  + Personal responsibilities such as Health, Finances, Writing, ..

- *Resources* - A range of topics you're interested in and learning about
  + Graphic design
  + Personal productivity
  + Modern Architecture

- *Archive* - Include anything from the previous three categories that is no longer active, but you might want to save for future reference
  + Projects you've competed or put on hold
  + Areas that are no longer active or relevant
  + Resources that you're no longer interested in
